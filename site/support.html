Support

ShareCursor is an early-development open-source project. Documentation and community support are public so fixes can benefit everyone.

install and configure

  • Start with the quickstart.
  • Use the installation guide for macOS permissions and Windows warnings.
  • Review configuration and troubleshooting for connection and input issues.

report a problem

Search the existing issues first. If the problem is new, open a bug report and include both operating-system versions, the ShareCursor version, the role of each computer, and reproducible steps.

Do not include the shared passphrase, private clipboard contents, transferred files, or other secrets in an issue or log excerpt.

request an improvement

Use the feature request form. Explain the two-computer setup and the problem the change would solve.

report a security vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private security advisory form so maintainers can review the report before details are disclosed.
