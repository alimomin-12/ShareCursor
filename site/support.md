# Support — ShareCursor

> ShareCursor is an early-development open-source project. Documentation and community support are public so fixes can benefit everyone.

## Install and configure

- Start with the [quickstart](https://docs.sharecursor.com/quickstart).
- Use the [installation guide](https://docs.sharecursor.com/installation) for macOS permissions and Windows warnings.
- Review [configuration](https://docs.sharecursor.com/configuration) and [troubleshooting](https://docs.sharecursor.com/troubleshooting) for connection and input issues.

## Report a problem

Search the [existing issues](https://github.com/phun333/ShareCursor/issues) first. If the problem is new, open a [bug report](https://github.com/phun333/ShareCursor/issues/new?template=bug_report.yml) and include both operating-system versions, the ShareCursor version, the role of each computer, and reproducible steps.

Do not include the shared passphrase, private clipboard contents, transferred files, or other secrets in an issue or log excerpt.

## Request an improvement

Use the [feature request form](https://github.com/phun333/ShareCursor/issues/new?template=feature_request.yml). Explain the two-computer setup and the problem the change would solve.

## Report a security vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's [private security advisory form](https://github.com/phun333/ShareCursor/security/advisories/new) so maintainers can review the report before details are disclosed.

## System requirements

| Platform | Supported setup |
|---|---|
| macOS | macOS 11 or newer; Accessibility and Input Monitoring permissions |
| Windows | Windows 10 or 11, x64; private-network firewall access |
| Network | Both computers on the same trusted LAN or Wi-Fi network |
